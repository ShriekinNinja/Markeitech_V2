# Archived V1 Run Configurations

These XML files are the complete shared PyCharm launchers from the preserved V1 runtime. They were
moved out of `.run/` during V2 repository onboarding so PyCharm does not present obsolete commands
as active choices on a fresh machine.

They are historical evidence only. Do not copy them back into `.run/` unless V1 is deliberately
reactivated through a separate reviewed decision.
