# Kite Focused Skill Library

Kite supports scoped engineering and market-evidence work through domain skills used directly by
the primary agent. Issue [#63](https://github.com/ShriekinNinja/Markeitech_V2/issues/63) replaces the
mandatory twenty-advisor council with this workflow. The existing router command remains
compatible; it selects guidance rather than dispatching a council.

## Sources And Activation

- [Kite entrypoint](../../plugins/kite/skills/markeitech-advisor-router/SKILL.md): activation,
  proportional investigation, and optional independent review.
- [Skill index](../../plugins/kite/skills/markeitech-advisor-router/references/skill-index.md):
  navigation to retained domain knowledge, not a coverage checklist.
- Each domain `SKILL.md`: targeted checks and optional detailed references.
- [Behavior checks](../../plugins/kite/skills/markeitech-advisor-router/references/behavior-checks.md):
  realistic maintenance evaluation prompts and observable criteria.
- [Operations](../operations/kite.md): versioning, identity, installation, fresh tasks, and rollback.

Kite and its domain skills remain explicit-only. Installation and casual discussion do not
activate them. Once explicitly selected, the primary agent chooses guidance without requiring
Markeitect to name a skill. Direct specialist invocation is scoped to that question.

## Everyday Behavior

Start with the requested result and the affected implementation. Read a skill or reference only
to resolve a specific uncertainty. A small shutdown correction does not reopen accepted component
ownership. A display-only change does not revalidate the displayed metric. A new provider owner
does warrant a comparison of relevant ownership and framework contracts.

Expand only for an observed defect, conflicting authority, or missing fact with a concrete effect
on the requested result. Explain the connection and preserve approval boundaries. Suggestions for
unrelated improvements remain outside the implementation scope. Finish with the result, evidence,
smallest correction or next check, and material limits; omit empty audit sections.

Source quality, mathematical correctness, domain meaning, and consumer fitness remain distinct.
They require evidence, not separate agents or signed-off dispositions. Missing evidence still
blocks the affected conclusion. Skills do not grant execution, legal, connected-service, or
project-decision authority. Sir Loke and runtime ownership are unchanged.

## Optional Review And Retirement

Default to no delegation. One independent read-only reviewer may answer a named question when it
adds material confidence. It uses the relevant skills, cannot delegate, and does not impose a
follow-on council. Broader multi-agent work requires an explicit user request. Inherit the task's
model/effort unless the user specifies otherwise. Review unavailability is disclosed; it does not
prevent direct evidence-based work or waive a real evidence/authorization requirement.

The twenty `.codex/agents/markeitech-*-advisor.toml` roles, council policy, allocation/dispatch
resolvers, their tests, and old routing exercises are retired together. Old allocation and council
acceptance records remain in Git history. No host settings or unrelated agents are removed.
The package manifest is now the sole package-version owner.

## Verification And Limits

The dependency-free library validator checks discoverable entrypoints, local links, explicit-only
metadata, absence of retired project roles, and the skill-only package boundary. Package tests
cover versioning and byte identity. These checks do not prove natural-language behavior.

Use the maintenance behavior prompts with independent evaluators and record actual results in
[the issue #63 evaluation](kite-focused-skills-evaluation.md). Source-directed evaluation is
separate from installed discovery. No quality, cost, latency, or technical isolation improvement
is inferred from fewer files or passing checks. Markeitect reviews usefulness on the PR; no agent
awards his acceptance. Plugin installation remains a separately authorized operation.
