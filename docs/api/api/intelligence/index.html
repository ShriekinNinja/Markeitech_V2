    markeitech.intelligence.CompletedBarInputIdentity dataclass ¶

    Identify one exact upstream path contributing to a canonical bar.

    Canonical series identity is intentionally independent of the provider path which supplied an observation. Historical one-minute and live five-second inputs therefore converge into one output series while each lineage entry preserves its exact provider, adapter, stream, raw selector, and source schema identity.

    Attributes:

    • provider_id (str) –

      Bounded provider identity, such as IB.

    • adapter_id (str) –

      Bounded adapter implementation identity.

    • source_stream_id (str) –

      Exact upstream stream or request-lane identity.

    • source_selector (str) –

      Exact raw input selector or native bar type.

    • source_schema_id (str) –

      Exact schema identity of the upstream observation.

    Raises:

    • ValueError –

      If an identity is empty, non-ASCII, or exceeds its bound.
