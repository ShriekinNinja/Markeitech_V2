    Command-Line Entry Point¶

    markeitech.cli.main ¶

    main(argv: Sequence[str] | None = None) -> int

    Route one explicit Markeitech runtime or repository operation.

    The command hierarchy owns parsing and fixed child-process mappings only. Runtime behavior remains owned by markeitech.system.cli; API documentation and diagrams remain in their isolated locked tool projects. No command provisions dependencies, starts Docker, supplies the Interactive Brokers confirmation, or broadens connected or persistence authority.

    Parameters:

    • argv (Sequence[str] | None, default: None ) –

      Optional command-line arguments. None reads process arguments.

    Returns:

    • int –

      The selected in-process owner or fixed child process exit code.

    Raises:

    • SystemExit –

      If command-line parsing or exact connection confirmation fails.

    • KeyboardInterrupt –

      If the operator interrupts command execution.
